# 安卓安装态（HTTPS + 装到主屏幕）

安卓 Chrome 只允许在**安全上下文**（HTTPS 或 localhost）里安装 PWA。局域网 IP
`http://<你的IP>:8000` 不满足 → 「添加到主屏幕 / 安装应用」不会出现。
装态 = 给控制层套一层**自签 HTTPS**，并在手机上信任一次本地根证书。

> 只影响安卓的**安装**能力，不影响日常使用：纯 HTTP 也能开浏览器正常用。

---

## 总流程（只做一次，约 5 分钟）

```
① 生成证书(make_cert.bat)
        │
② 手机下载并信任根证书  ← 必须在这时做，之后就是 HTTPS，看不到这个下载页
        │   http://<你的IP>:8000/ca.crt
        ▼
③ 重启 run.bat https → HTTPS → 手机装 PWA
```

## 详细步骤

### ① 生成证书

双击 `make_cert.bat`（或在 cmd 里 `python make_cert.py`）。产物在 `certs\`：

| 文件 | 作用 | 有效期 |
|---|---|---|
| `ca.crt` | 本地根证书，**手机装它** | 10 年 |
| `ca.key` | 根私钥，**只留本机**，别外传 | — |
| `server.crt` / `server.key` | 服务器证书，`run.bat` 自动加载 | 397 天 |

默认局域网 IP 自动探测（也可 `--ip` 指定）。IP 变了就重跑：
`python make_cert.py --ip <新IP> --force`。

### ② 手机信任根证书

生成证书后，跑普通的 `run.bat`（默认就是 HTTP，专门用来给手机下载根证书——
此刻还没信任证书，直接开 HTTPS 会显示警告）。手机用 Chrome 打开：

```
http://<你的IP>:8000/ca.crt
```

1. 会下载 `ca.crt`，点通知栏或文件管理器里的这个文件
2. 安卓弹「安装证书」→ 选 **CA 证书**
3. 若提示先设锁屏 **PIN/图案**——照做，安卓装证书的硬性要求
4. 遇到「网络可能受到监控」警告 → 这是安卓对"用户安装的 CA"的统一提示，点**仍然安装**

装完即信任。之后控制层开 HTTPS，Chrome 不会再有证书警告。

### ③ 重启 run.bat https → 装 PWA

- 关掉旧窗口，双击 `run.bat https`（必须带 `https` 参数才走 HTTPS）：
  `https://<你的IP>:8000`（日常开发/调试用不带参数的 `run.bat`，即纯 HTTP）
- 手机 Chrome 打开 `https://<你的IP>:8000`（地址栏小锁正常、无警告）
- 右上角菜单 **⋮ → 添加到主屏幕 / 安装应用**（或等底部弹出安装横幅）

装上后图标进桌面，点开即独立窗口，可离线打开壳、联网才出图。

## 日常 / 维护

| 场景 | 做法 |
|---|---|
| 换局域网 IP | `make_cert.bat` 里用 `--ip 新IP --force` 重生成 → 手机重装根证书 → 重启 run.bat https |
| 服务器证书过期（近 400 天） | 重跑 `python make_cert.py --ip <你的IP> --force` → 手机重装 `ca.crt` |
| 想退回纯 HTTP | 直接跑普通 `run.bat`（默认 HTTP）；HTTPS 只在 `run.bat https` 时才启用，证书留着不影响 |
| 装了 HTTPS 后手机打不开 | ①证书没装/没装对 → 重做②；②开的是 http 端口 → 改 `https://` |

## 常见问题

**为什么装了根证书 Chrome 还警告？**
多半是装了 `server.crt` 而不是 `ca.crt`，或装成了「VPN 和应用」/「用户证书」而非
「CA 证书」。删掉已装的，重做②选 **CA 证书**。

**PWA 菜单还是只有「添加到主屏幕」、没有「安装应用」？**
两者都算安装路径；「添加到主屏幕」在新 Chrome 上已等于安装。若想确定装的是 PWA：
装完打开图标，应是无地址栏的独立窗口（standalone）。如果仍是浏览器壳，在 Chrome
里清一次该站点数据（⋮ → 设置 → 网站设置 → 该站点 → 清除并重置），重新访问再装。

**改了 ACCESS_TOKEN 后 HTTPS 打不开？**
鉴权与证书无关——静态壳不被拦。若页面 401 是令牌没填，到设置页输入即可（与 HTTP
完全一致）。
